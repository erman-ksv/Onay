# Onay

Onay — приложение для заказа мест в общем такси на линиях между посёлками и городом. Пассажир и водитель используют одно мобильное приложение; администратор управляет маршрутами и пользователями через отдельную веб-панель.

Сервер поддерживает настроенные маршруты в обе стороны, очередь водителей, предложения заказов, резервирование мест и внешнюю подачу с подтверждением цены. Полный мобильный сценарий, реальные SMS/push и приёмка на физических телефонах продолжают развиваться. Наличие серверного API не означает готовность приложения к публикации.

| Каталог | Назначение |
| --- | --- |
| `mobile/onay-app` | Мобильное приложение Onay на Expo для Android/iOS |
| `artifacts/api-server` | Backend API и события Socket.IO |
| `artifacts/mockup-sandbox` | Веб-панель администратора и существующие прототипы |
| `lib/db` | PostgreSQL, схема и миграции |
| `docs` | Чек-лист, контракты и результаты проверок |

Onay Agents Factory — отдельный инструмент разработки, который хранится в отдельном репозитории. Он не является частью пассажирского приложения.

## Разработка и проверки

Используется pnpm. Установка зависимостей: `pnpm install --frozen-lockfile`. Проверка типов: `pnpm run typecheck`. API-тесты: `pnpm test`; для интеграционных сценариев необходим настоящий PostgreSQL и настроенный `DATABASE_URL`.

Мобильное приложение имеет собственные зависимости и команды в [`mobile/onay-app/README.md`](mobile/onay-app/README.md). Настройка сервера описана в [`artifacts/api-server/README.md`](artifacts/api-server/README.md), административной панели — в [`ADMIN_PORTAL.md`](artifacts/mockup-sandbox/ADMIN_PORTAL.md).

## Названия и совместимость

Актуальное имя продукта — **Onay**. Имя инструмента разработки — **Onay Agents Factory**. Подробности перехода конфигурации и сохранённых данных приведены в [документе переименования](docs/ONAY_REBRANDING.md).

Исходные пункты проекта сохранены в [полном чек-листе](docs/ONAY_CHECKLIST.md). Переименование не закрывает дополнительные функциональные задачи и не меняет процент реализации.
