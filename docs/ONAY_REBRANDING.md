# Onay: названия и совместимость

Пользовательские названия: **Onay** для приложения и **Onay Agents Factory** для отдельной системы разработки. Это переименование продукта; правила очереди, мест, тарифов и поездки остаются прежними.

## Канонические имена

| Область | Имя |
| --- | --- |
| Приложение и веб-панель | `Onay` |
| Каталог мобильного клиента | `mobile/onay-app` |
| Expo slug и URL scheme | `onay` |
| Android application ID / iOS bundle identifier | `uz.onay.app` |
| Мобильный пакет | `onay-mobile` |
| Корневой пакет | `onay` |
| Новые переменные окружения backend | `ONAY_*` |
| Целевое имя репозитория приложения | `erman-ksv/Onay` |
| Отдельный инструмент | `Onay Agents Factory` |
| Целевое имя его репозитория | `erman-ksv/Onay-Agents-Factory` |

Названия самих репозиториев меняются отдельно через настройки GitHub. Изменение файлов не переименовывает репозиторий. В отчёте выполнения требуется проверять фактические canonical `full_name` обоих репозиториев, а не считать целевые имена уже применёнными.

## Настройки существующего сервера

Новая конфигурация использует `ONAY_STORAGE_ADAPTER`, `ONAY_OFFER_TIMEOUT_SECONDS`, `ONAY_OSRM_URL` и `ONAY_OTP_*`. Существующие `TEZJET_*` принимаются только как прежние имена: новая переменная при наличии имеет приоритет. Заданное, но неверное новое значение не должно молча заменяться старым допустимым.

`DATABASE_URL`, `SESSION_SECRET`, `ADMIN_PHONE` и прочие переменные без прежнего названия продукта не меняются. Секреты не заменяются при смене бренда. В GitHub Actions переменная `ONAY_API_URL` используется первой, `TEZJET_API_URL` оставлена как совместимый резерв для существующей настройки репозитория.

## Сохранённые данные

В мобильном клиенте новые имена ключей начинаются с `onay_`; чтение и перенос старых токена и адреса API должны сохранять существующие настройки в том же хранилище. Новый Android/iOS идентификатор определяет приложение Onay; автоматический перенос данных между разными установленными приложениями этим кодом не обещается.

Физические таблицы PostgreSQL `tezjet_users`, `tezjet_otp_challenges`, `tezjet_driver_queue`, `tezjet_orders`, `tezjet_device_registrations`, `tezjet_routes`, их существующие индексы и история применённых SQL-миграций сохраняются. Они являются идентификаторами существующего хранилища. Изменение этих строк без отдельной миграции создало бы другое хранилище либо нарушило доступ к имеющимся пользователям и заказам.

Существующие криптографические разделители для сохранённых кодов OTP и внешних предложений также не меняются ради названия: иначе уже выпущенные данные могли бы перестать проверяться. Эти технические идентификаторы и совместимые старые настройки — допустимые остаточные упоминания прежнего имени, а не отображаемое название приложения.

Исторические коммиты, ссылки на прошлые PR/CI и работа в других незавершённых ветках не переписываются автоматически. Пока canonical имя репозитория GitHub остаётся `erman-ksv/TezJet`, ссылки на доказательства сохраняют этот действующий адрес; после переименования GitHub перенаправляет старые ссылки. Целевой адрес не подставляется в исторические доказательства до проверки самого переименования. Новый исходный код и инструкции используют актуальные названия; прежняя история остаётся проверяемой.
