# 🚕 TezJet — полный рабочий чек-лист

Снимок для этапа PR #34, 14 октября 2026 года. Сохранены все 172 исходные задачи: 151 TezJet и 21 Agent-Factory.

**Показатель реализации: 47,0% — 71 из 151 пункта TezJet.** 44 подтверждены в указанной области, 27 реализованы и ожидают приёмки, 47 выполнены частично, 33 не подтверждены/не сделаны. В расчёт входят подтверждённые и реализованные пункты; частичные не засчитываются. Это объём реализации, а не готовность к релизу. Agent-Factory учитывается отдельно. Для минимум 65% нужно 99 из 151 — остаётся 28 пунктов.

**Дельта текущего этапа: один пункт — 9.4, управление питаками A/B и остановками.** 70 → 71, 46,4% → 47,0%. API-only добавления PR #24–#31 сами по себе завершёнными пунктами не считаются. Два ранее неподтверждённых административных пункта переведены в частичные: API просмотра заказов и статистики поездок есть, полноценные экраны/действия ещё нужны.

В PR #34 администратор создаёт маршрут, добавляет/редактирует/переставляет/удаляет остановки, выбирает их координаты нажатием на реальную карту или вводит вручную, задаёт A/B и радиус. Выбор на карте становится частью этого же пункта по уточнению пользователя; до его реализации и браузерной проверки пункт не объединяется. Данные сохраняются в PostgreSQL. Одновременная чужая правка даёт 409 и сохраняет локальный черновик. Перед объединением необходим зелёный финальный CI и браузерный прогон. Smart Pickup, живой GPS, настоящая SMS-доставка и production-развёртывание этим этапом не завершаются.

Проверки исходного кода этапа: [PR #34](https://github.com/erman-ksv/TezJet/pull/34), [API148/148](https://github.com/erman-ksv/TezJet/actions/runs/38531986084), [Chromiumdesktop/390px](https://github.com/erman-ksv/TezJet/actions/runs/38531986064). Финальный прогон после визуального исправления заголовка и дополнительных проверок удаления/перестановки обязателен. Прочие статусы взяты из предыдущего реестра и дополнены известными результатами PR #23–#31; это не новая полная приёмка всех функций.
